## DOCX versions

DOCX exports are in [`../../docx/references/en/`](../../docx/references/en/).

Generate or update a single file:
```bash
make docx-one FILE=handouts/references/en/reference-zouden.md
```

Regenerate all reference sheets (Dutch + English):
```bash
make docx-refs
```
