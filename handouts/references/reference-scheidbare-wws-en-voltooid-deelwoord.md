## Separable Verbs Explained

### What is a Separable Verb?

A **separable verb** is a verb composed of a **prefix** + a **base verb**. In the present tense, the prefix separates and goes to the end of the sentence.

**Pattern:** Subject + Base Verb + ... + Prefix

| Infinitive | Present Tense | English |
|-----------|----------------|---------|
| opbellen | Ik **bel** je **op** | I call you up |
| aansteken | Ik **steek** het vuur **aan** | I light the fire |
| uitnodigen | Ik **nodig** je **uit** | I invite you |
| weggaan | Ik **ga** **weg** | I'm leaving |
| ophangen | Ik **hang** mijn jas **op** | I hang up my coat |

### Perfect Participle: The Key Rule

For **separable verbs**, the **ge-** goes **between the prefix and the verb stem**:

**Prefix + ge + Stem + (t/d)**

| Infinitive | Prefix | Stem | Perfect Participle | English |
|-----------|--------|------|---------------------|---------|
| opbellen | op | bel | **opge**bel**d** | called up |
| aansteken | aan | steek | **aangeste**ken | lit |
| uitnodigen | uit | nodig | **uitgenodig**d | invited |
| weggaan | weg | ga | **weggegaan** | left |
| ophangen | op | hang | **opgehangen** | hung up |
| wegzetten | weg | zet | **weggezet** | put away |
| nadenken | na | denk | **nagedacht** | thought about |
| binnenkomen | binnen | kom | **binnengekomen** | came in |
| klaarmaken | klaar | maak | **klaargemaakt** | prepared |
| schoonmaken | schoon | maak | **schoongemaakt** | cleaned |

### Examples in Context

| Sentence | English | Notes |

## Perfect Participle Formation

### Regular Verbs: The 3 Steps

1. **Remove -en** from the infinitive to get the stem
2. **Add ge-** at the beginning
3. **Add -t or -d** based on the stem ending

### Step 1: Find the Stem

| Infinitive | Remove -en | Stem |
|-----------|------------|------|
| werken | werk | **werk** |
| lopen | loop | **loop** |
| spelen | speel | **speel** |
| maken | maak | **maak** |
| koken | kook | **kook** |
| stoppen | stop | **stop** |

### Step 2 & 3: Add ge- + ending

See [The Soft Ketchup Rule](#the-soft-ketchup-rule) below.

## The Soft Ketchup Rule

### The Simple Rule

**Add -t** if the stem ends in: **F, S, T, K, P, Ch**
**Add -d** for all other stem endings

Mnemonic: **S**oft **K**etch**u**p **T**astes **F**antastic **P**lease **Ch**eer

### Clear Examples

| Verb | Stem | Stem ends in... | Participle | Why? |
|------|------|-----------------|------------|------|
| werken | werk | **k** | gewerkt | k is in list → **-t** |
| lopen | loop | o | gelopen | o not in list → **-d** |
| spelen | speel | l | gespeeld | l not in list → **-d** |
| stoppen | stop | **p** | gestopt | p is in list → **-t** |
| koken | kook | **k** | gekookt | k is in list → **-t** |
| hangen | hang | ng | gehangen | ng not in list → **-d** |
| zetten | zet | **t** | gezet | t is in list → **-t** |
| denken | denk | **k** | gedacht | k is in list → **-t** |
| maken | maak | **k** | gemaakt | k is in list → **-t** |
| wonen | woon | n | gewoond | n not in list → **-d** |
| nodigen | nodig | g | genodigd | g not in list → **-d** |

## Key Takeaways

### 1. Separable Verb Pattern
- **Infinitive:** prefix + verb (e.g., **op**bellen, **aan**steken)
- **Present:** subject + verb + ... + prefix (e.g., *Ik **bel** je **op***)
- **Perfect:** prefix + **ge** + stem + t/d (e.g., **opge**beld)

### 2. Soft Ketchup for t vs d
- **Add -t** if stem ends in: **F, S, T, K, P, Ch**
- **Add -d** for all other endings

### 3. Exceptions to Remember
- **bestellen** → **besteld** (NO ge-!)
- **brengen** → **gebracht** (irregular)
- **gaan** → **gegaan** (irregular)
- **komen** → **gekomen** (irregular)
- **zijn** → **geweest** (irregular)

### 4. Prefix Position in Perfect Tense
- **binnenkomen** → **binnengekomen** (ge goes after prefix)
- **meebrengen** → **meegebracht** (prefix stays, verb irregular)
- **meenemen** → **meegenomen** (ge after prefix, then verb stem)

## Quick Test Yourself

Conjugate in perfect tense:

1. Ik ... (opbellen) mijn vriend gisteren. → *Ik heb mijn vriend opgebeld.*
2. Zij ... (aansteken) de kaarsen. → *Zij heeft de kaarsen aangestoken.*
3. We ... (uitnodigen) al onze vrienden. → *We hebben al onze vrienden uitgenodigd.*
4. Hij ... (weggaan) zonder afscheid te nemen. → *Hij is weggegaan zonder afscheid te nemen.*
5. Heb je je sleutels ... (meenemen)? → *Heb je je sleutels meegenomen?*
6. Ik ... (opeten) mijn ontbijt al. → *Ik heb mijn ontbijt al opgegeten.*
7. Zij ... (schoonmaken) de hele woning. → *Zij heeft de hele woning schoongemaakt.*
8. Wanneer ... (terugkomen) jij? → *Wanneer ben je teruggekomen?*
9. Ik ... (bestellen) een koffie. → *Ik heb een koffie besteld.*
10. Hij ... (brengen) bloemen mee. → *Hij heeft bloemen meebracht.*
