# Handout S11 — Ik heb bloemen voor je meegebracht

**Datum:** Donderdag 14 mei 2026
**Unit:** 09 — *ik heb bloemen voor je meegebracht* *(I've brought you flowers)*
**Boek:** blz. 109–120
**Duur:** 2 uur

## **Leerdoelen**
✅ Je kunt **mensen uitnodigen** en afspraken maken
✅ Je kunt **zullen** gebruiken voor aanbiedingen, suggesties en toekomstplannen
✅ Je begrijpt de vier regels voor **scheidbare werkwoorden** (hoofdwerkwoord, infinitief, te, voltooid deelwoord)
✅ Je kunt **om + te + infinitief** gebruiken om een doel uit te drukken
✅ Je weet het verschil tussen **zin hebben om + te** en **zin hebben in**
✅ Je kunt **voorkeuren uitdrukken** (heb liever, het liefst)
✅ Je weet dat na **iets / niets** het bijvoeglijk naamwoord **-s** krijgt

## **Grammatica**

### **1. Zullen (shall/will)**
Gebruikt voor: **suggesties** ("zullen we…?"), **aanbiedingen** ("zal ik…?"), **toekomstplannen**, **beloftes**

| **Enkelvoud** | **Meervoud** |
|---------------|--------------|
| ik **zal** | wij/we **zullen** |
| jij/je **zult/zal** | jullie **zullen** |
| u **zult/zal** | zij/ze **zullen** |
| hij/zij/het **zal** | |

**Voorbeelden:**
- **Zal ik** de tafel dekken? *(Shall I set the table?)*
- **Zullen we** morgen afspreken? *(Shall we meet tomorrow?)*
- Ik **zal** er om acht uur zijn. *(I'll be there at eight.)*

---

### **2. Scheidbare werkwoorden**
Een scheidbaar werkwoord bestaat uit een prefix en een werkwoord. Het prefix scheidt afhankelijk van de zinsconstructie.

| **Geval** | **Regel** | **Voorbeeld** |
|-----------|-----------|---------------|
| a. Hoofdwerkwoord | prefix → einde van de zin | Ik **breng** bloemen voor je **mee**. |
| b. Infinitief na modaal | prefix blijft aan werkwoord | Ik wil je **uitnodigen**. / Wij zullen **afwassen**. |
| c. Met *te* | *te* gaat tussen prefix en werkwoord | Ik heb geprobeerd om je op **te bellen**. |
| d. Voltooid deelwoord | *ge-* gaat tussen prefix en werkwoord | Ik heb mijn jas **op**ge**hangen**. / Ik heb bloemen **mee**ge**bracht**. |

**Scheidbare werkwoorden in deze les:**

| **Werkwoord** | **Betekenis** |
|---------------|---------------|
| meebrengen | to bring along |
| meegeven | to pass on / give along |
| meenemen | to take along |
| meekomen | to come along |
| uitnodigen | to invite |
| afspreken | to arrange / meet up |
| klaarmaken | to prepare |
| uitproberen | to try out |
| afwassen | to wash up |
| weggaan | to go away |
| aansteken | to light |
| opbellen | to phone / ring up |

---

### **3. Om + te + infinitief**
Gebruik *om + te + infinitief* om een **doel of bedoeling** uit te drukken (= in order to):

- Ik ga naar de supermarkt **om** boodschappen **te doen**. *(I'm going to the supermarket to do the shopping.)*
- Ik heb bloemen meegebracht **om** jou **te bedanken**. *(I brought flowers to thank you.)*
- We willen jullie uitnodigen **om** bij ons **te komen eten**. *(We want to invite you to come and eat with us.)*

> Let op: bij scheidbare werkwoorden gaat *te* tussen prefix en werkwoord: *om je op **te** bellen*, *om niet op **te** eten*.

**Zin hebben om + te vs. zin hebben in:**

| | **Gebruik** | **Voorbeeld** |
|---|-------------|---------------|
| *zin hebben **om** + te* | gevolgd door een actie | Hebben jullie zin **om** zaterdag **te komen**? |
| *zin hebben **in*** | gevolgd door een voorwerp | Ik heb zin **in** koffie. |

### **4. Voorkeuren uitdrukken**
| **Nederlands** | **Engels** |
|----------------|------------|
| Wil je rode wijn of heb je liever pils? | Would you like red wine or would you prefer lager? |
| Ik heb liever pils. / Liever pils. | I'd prefer lager. |
| Ik drink het liefst koffie | I like coffee most of all |
| Wij eten liever vegetarisch | We prefer to eat vegetarian |
| Ik geef de voorkeur aan… | I prefer… (formeel) |

### **5. Iets / niets + bijvoeglijk naamwoord**
Na *iets* en *niets* krijgt het bijvoeglijk naamwoord een extra **-s**:

| **Nederlands** | **Engels** |
|----------------|------------|
| iets **sterkers** | something stronger |
| iets **lekkers** | something tasty |
| niets **nieuws** | nothing new |
| niets **moois** | nothing beautiful |
